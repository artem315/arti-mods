# Арти Модс

Первая рабочая версия независимого каталога модов Minecraft: регистрация и вход, поиск, фильтры, избранное, личные проекты, загрузка JAR/ZIP/MRPACK (до 30 МБ), карантин, очередь VirusTotal, скачивание проверенных файлов.

## Запуск

Node.js 24 или новее. Внешние пакеты не требуются.

```sh
npm start
```

Открыть http://localhost:3000. Проверки: `npm test`.

## Render

Создать Web Service из Git-репозитория. Build: `npm install --omit=dev`, Start: `npm start`. Node 24.19.0. Health check `/api/health`.

Переменные окружения:

* `NODE_ENV=production`
* `APP_ORIGIN=https://<ваш-сервис>.onrender.com` — точный публичный origin для проверки запросов.
* `VIRUSTOTAL_API_KEY` — секретный ключ VirusTotal, только на сервере.
* `DATA_DIR=/var/data/arti-mods` — при подключённом постоянном диске `/var/data`.

Без ключа файлы остаются в закрытой очереди. После добавления ключа и перезапуска очередь продолжится автоматически. По одному запросу VirusTotal раз в 21 секунду; ошибки оставляют файл в карантине. Успешный анализ требует статуса completed, хотя бы одного обработавшего движка и отсутствия malicious/suspicious. Полностью нераспознанные файлы остаются на проверке.

ВАЖНО: бесплатный Render имеет временную файловую систему: аккаунты и файлы исчезают после пересоздания сервиса. Для рабочего каталога требуется постоянный диск или перенос данных в внешние БД и объектное хранилище. Не принимать реальные загрузки до настройки постоянного хранения. В бесплатной публикации предусмотрен режим демонстрации без регистрации и загрузок.

Файлы отправляются в публичный набор VirusTotal только после согласия автора. Условия и квоты своего API-тарифа нужно проверить перед рабочим использованием. Отсутствие обнаружений не гарантирует безопасность.

## Границы первой версии

Один файл/версия на проект; нет восстановления пароля, подтверждения email, команд авторов, жалоб, административной модерации и резервного копирования. Перед масштабированием добавить модерацию и управление проектами, внешнее хранилище, распределённые лимиты запросов, резервное копирование и наблюдаемость. Использовать один процесс сервера с SQLite.
