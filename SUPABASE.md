# Постоянное хранилище на бесплатном Render

Сервер поддерживает PostgreSQL и закрытый Supabase Storage. Без настроек локально используется SQLite. На Render регистрация разрешается только при подключении обоих постоянных хранилищ.

## Настройки Render → Environment

- `DATABASE_URL`: строка PostgreSQL из Supabase Connect → Session pooler (IPv4), с паролем и `sslmode=verify-full`. Не отключать проверку сертификата.
- `SUPABASE_URL`: `https://msoaxodmewylttgzogtf.supabase.co`
- `SUPABASE_SERVICE_ROLE_KEY`: серверный service_role key (или серверный secret key). Только секрет Render, никогда не GitHub и не клиентский код.
- `SUPABASE_BUCKET`: `arti-mods-private`
- `DEMO_MODE`: `false`, после настройки базы и бакета.
- `VIRUSTOTAL_API_KEY`: ключ для настоящей проверки. Без ключа файлы остаются в карантине и недоступны для скачивания.

Бакет должен быть PRIVATE, без политик чтения для anon/authenticated. Сервер проверяет это при запуске. Таблицы создаются в отдельной схеме `arti`, за пределами публичного Data API. Резервные копии базы и файлов нужно настраивать отдельно.

Лимит приложения: 800 МиБ файлов суммарно, один файл до 30 МиБ. Это стартовый MVP, один файл и одна версия на проект. Проверки VirusTotal не являются гарантией отсутствия вредоносного кода.

Перед открытием регистрации проверить реальную запись в PostgreSQL, загрузку в приватный бакет и сохранение данных после перезапуска Render. Локальные тесты проверяют карантин и обработку ответов VirusTotal, но не заменяют эту проверку облака.
